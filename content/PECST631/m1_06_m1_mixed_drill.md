## 4. Active Recall Quizzes

::: quiz Q1: Mixed Drill
Beizer level of a suite with only happy-path demos:
(A) Level 3 (evaluative!)
(*B) Level 1 (demonstrate-it-works theatre! — no adversarial content: boundaries/nulls/loads absent!) — audit content, not count
(C) Level 4 (preventive!)
(D) Level 2 (destructive!)
::: explanation
Intent-evidence audit (adversarial cases present?) levels suites (demos ≠ destruction!). Content audit beats count/size claims — look for edge arsenals, not test totals.
:::

::: quiz Q2: Mixed Drill
V&V labels: compiler warning triage vs beta-user trial?
(A) Both validation
(*B) Warning-triage (spec-conformance-ish static gates!) leans verification; beta-trial (real users, real needs!) is validation — question-asked decides (conforms? vs wanted?)
(C) Both verification
(D) Neither qualifies
::: explanation
Question test (which question answered: spec-conformance? user-need?) labels activities (reviews/static/unit-ish lean V; UAT/beta lean V&V... validation!). Activity-sorting by question is the V&V reflex.
:::

::: quiz Q3: Mixed Drill
Pyramid violation smell in numbers (unit:E2E = $1$:$5$):
(A) Healthy Pyramid
(*B) Ice-cream cone (inverted economics: slow/flaky peak bulk! — rebalance toward base: unit-fill cheap gaps, E2E-trim to critical paths, quarantine flakes!)
(C) Ideal ratio
(D) Means thorough E2E (thorough *and* bankrupt — virtues need budgets!)
::: explanation
Ratio-reading ($1$:$5$ inverted vs $7$:$2$:$1$-ish healthy!) diagnoses shape (numbers tell!). Prescription trio (fill-base/trim-peak/quarantine!) completes the audit — diagnose then rebalance.
:::
