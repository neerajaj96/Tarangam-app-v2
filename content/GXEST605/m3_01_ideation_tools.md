## 2. Theoretical Framework & Formalism

### 2.1 Stages + tool roster + capture protocol

* Stages (brief → diverge → cluster → converge → shortlist!).
* Divergent: brainstorming (rules!), SCAMPER (verb-prompts!), six hats (role-parallelism!), random entry, worst-idea inversion (taboo-flip creativity!).
* Convergent: affinity, dot-vote (dotted democracy with criteria announced!), decision matrix (weighted scoring!), SWOT (internal/external split!), Pugh (datum-comparison!).
* Capture: log format (idea/author/trigger/date!) + idea bank rituals (weekly review!).

::: callout-formula KTU Formula Vault: Ideation
Storm (rules!) → cluster → sieve (matrices!) → log (banked!) · hats parallelise · SCAMPER verbs provoke.
:::

::: callout-pitfall Converging During Diverging (Evaluation Erosion!)
Judgment leaks ("that'll never work" mid-storm!) strangle wild ideas (self-censorship cascades!) — facilitator polices phases (parking-lot for concerns, storm purity guarded!). Phase purity (diverge-pure then converge-hard!) is the facilitation prime directive.
:::

## 3. Worked Example / Step-by-Step Scenario

::: step [Step 1: Setup] Formulating the Problem
"Canteen queue brief (M2 legacy!): (a) $6$ SCAMPER sparks? (b) Six-hats pass (one line per hat!)? (c) Decision matrix ($3$ finalists × impact/feasibility/cost!) with winner? (d) Capture log line format?"
:::

::: step [Step 2: Execution] Storm, Hats, Sieve, Jar
1. (a) Substitute tokens→QR! Combine pre-order+pickup-window! Adapt airport-boarding groups! Modify portion-flex pricing! Put display to *hostel* screens! Eliminate cash counter! Reverse: kitchens pull orders (not push queues!).
2. (b) White (facts: $20$-min peaks!) · Red (hangry dread!) · Black (caution: phone-less eaters!) · Yellow (pre-order calm!) · Green (drone delivery?! wild welcome!) · Blue (process control!).
3. (c) Weights impact $5$/feasibility $4$/cost $3$ (announced!): QR-tokens $23$ vs boarding-groups $19$ vs drones $11$ — winner QR-tokens (math shown!).
4. (d) Log: idea/author/trigger-hat/date + matrix score (banked!).
:::

::: step [Step 3: Conclusion] Final Result
Verb-sparks, hatted pass, scored sieve, banked log. Criteria-announced-before-scoring (no rigged matrices!) is the fairness lock.
:::

## 4. Active Recall Quizzes

::: quiz Q1: Foundational Concept
Six hats' parallel-thinking value over free debate is:
(A) Colourful stationery
(*B) Role-synchronised exploration (all-green wildness together, all-black caution together — no role-clashes/ego-duels!; full-spectrum coverage guaranteed per hat-round!)
(C) Faster meetings always
(D) Consensus forced
::: explanation
Parallelism dividend (same-mode-together!) avoids adversarial deadlock (black-vs-green trench warfare!) and guarantees neglected modes (red feelings *scheduled*!). Mode-discipline (hat-wearing announced!) is the facilitation lever.
:::

::: quiz Q2: Foundational Concept
Decision-matrix criteria weights announced *before* scoring prevents:
(A) Arithmetic errors
(*B) Motivated rigging (weights tuned to crown favourites post-hoc!) — pre-commitment binds (weights locked, then scores!) plus sensitivity notes (weight-wobble flips flagged!)
(C) Slow sessions
(D) Tie outcomes (ties legitimately occur — tie-break rules pre-set!)
::: explanation
Pre-commitment integrity (criteria+weights public before contenders scored!) — rigging-proofing by procedure (sensitivity checks as audit!). Procedural fairness (announced-then-applied!) legitimises outcomes.
:::

::: quiz Q3: Foundational Concept
Worst-idea inversion (deliberately terrible ideas first) works by:
(A) Comedy relief only (morale helps, secondary!)
(*B) Taboo-licensed wildness (permission to be absurd lowers bars — terrible ideas invert into gems: "ban all chairs" → standing-meeting pods!; plus constraint-revealing (why-terrible *names* real constraints!)
(C) Filling time
(D) Embarrassing juniors
::: explanation
Permission-structure flip (absurdity *assigned*!) plus inversion dividends (terrible→opposite-gem + constraint surfacing!). Licensed-wildness (explicit invitation!) outperforms hoping-for-wildness.
:::
