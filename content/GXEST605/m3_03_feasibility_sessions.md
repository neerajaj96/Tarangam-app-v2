# Feasibility Six-Pack & Session Tips

**Six lenses or blind — technical/economic/market/operational/legal/ethical checks plus sessions that actually decide.**

<a id="the-intuition"></a>
## 1. The Intuition

::: callout-intuition Core Mental Model: Six Bouncers at the Door
**Technical** (can we build it? skills/stack/TRL?!). **Economic** (numbers work? unit economics + payback!). **Market** (buyers exist at price? TAM-SOM says?!). **Operational** (can we *run* it daily? staffing/maintenance!). **Legal** (food-safety/data/IP compliances!). **Ethical** (should we? equity/privacy/externality audit!). **Sessions** that decide: pre-reads circulated, timeboxed storms, criteria-locked sieves, dissent-logged, banked-logged — tips as *protocol*, not vibes.
:::

<a id="the-math"></a>
## 2. Theoretical Framework & Formalism

### 2.1 Six checks + session protocol + kill criteria

* Per-lens verdicts (pass/concern/kill with evidence!) — any *kill* gates (single-veto rule? or weighted? — rule stated upfront!).
* Session tips (diverse seats! naive experts welcomed! breaks timed! parking lots honoured! energy managed — facilitation craft!).
* Kill criteria pre-set (unit-cost ceiling! compliance red-lines! payback horizon!) — pre-commitment vs sunk-cost drift.

::: callout-formula KTU Formula Vault: Six-Pack
Tech/econ/market/ops/legal/**ethical** · veto-rules **stated** · kill-lines **pre-set**.
:::

::: callout-pitfall Ethics-Last Sequencing (Compliance Theatre Endgame!)
Ethics reviewed *after* build-plans lock (sunk billions defend the indefensible!) — ethics *first-class early* (lens six of six from brief one!) with veto teeth. Sequence ethics early (cheapest veto point!) — order is the moral.
:::

## 3. Worked Example / Step-by-Step Scenario

::: step [Step 1: Setup] Formulating the Problem
"QR-token canteen system: six-lens verdicts (one line + evidence each!) + session plan (who/boxes/rules!) + kill lines?"
:::

::: step [Step 2: Execution] Six Verdicts, One Session
1. Technical: PASS (QR libs + display commodity! — spike-proven in $2$ days!). Economic: PASS-CONDITIONAL (₹$X$/term vs queue-hour savings — pilot-metered!). Market: PASS (captive hungry users!). Operational: CONCERN (who reboots displays? — rota named or kill!). Legal: PASS (no PII stored! — privacy-review signed!). Ethical: PASS (phone-less fallback mandatory — equity gate!).
2. Session: users+cook+warden+dev (seats!), $90$′ boxes (storm $30$/sieve $40$/decide $20$!), criteria pre-locked, dissent log open.
3. Kill lines: display-maintenance unowned OR fallback missing → KILL (pre-set, signed!).
:::

::: step [Step 3: Conclusion] Final Result
Verdict-per-lens with evidence, session with seats-and-boxes, kills pre-set. Single-veto transparency (which lens can kill alone!) stated upfront — governance visible.
:::

## 4. Active Recall Quizzes

::: quiz Q1: Foundational Concept
Single-lens veto (any kill gates) vs weighted scoring differs in risk posture by:
(A) Nothing practical
(*B) Veto = strong-sustainability logic (no tradeoffs on red lines: safety/equity/compliance!); weighted = compensatory (great economics offsets weak ethics — danger accepted!). Posture chosen per domain (safety-critical ⇒ veto!).
(C) Math complexity only
(D) Meeting length
::: explanation
Non-compensatory vs compensatory ethics (red-lines vs trade-space!) — governance philosophy with teeth. Veto-list publication (which lenses kill solo!) is the integrity signal.
:::

::: quiz Q2: Foundational Concept
Operational feasibility (run-it-daily) most-skipped because:
(A) Boring to discuss
(*B) Build-bias (launch dazzles, operations drudge — staffing/spares/rosters unsexy!; pilot-then-abandon graveyards testify!). Ops-first questions (who reboots at $2$am?!) asked at brief stage.
(C) Unknowable in advance
(D) Vendors cover it (contracts ≠ capability — verify!).
::: explanation
Day-two blindness (launch myopia!) kills pilots post-honeymoon (maintenance orphans!). Ops-lens parity (staffing/spares/rosters *in* the six!) forces day-two design day-zero.
:::

::: quiz Q3: Foundational Concept
Pre-set kill lines beat sunk-cost drift by:
(A) Pessimism signalling
(*B) Pre-commitment device (decided cool-headed, triggers fire automatically — escalation of commitment needs *heat*; cold rules starve it!). Sunk-cost psychology named and countered structurally.
(C) Faster meetings
(D) Fewer ideas needed
::: explanation
Commitment-device logic (Ulysses contracts for projects!) — triggers pull plugs that pride won't. Kill-line ceremony (written, signed, dated!) is governance against our future selves.
:::
