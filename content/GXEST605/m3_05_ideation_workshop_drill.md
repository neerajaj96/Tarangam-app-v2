## 3. Worked Example / Step-by-Step Scenario

::: step [Step 1: Setup] Formulating the Problem
"Brief: library seat-hunting chaos ($7$pm crunch!). Pressure-run: $4$ SCAMPER sparks + hats trio + $3$-finalist matrix + PoC question for winner?"
:::

::: step [Step 2: Execution] Pressure Answers
1. Sparks: Substitute paper-slips→QR check-in! Combine seat-map+waitlist! Adapt restaurant-pager buzzers! Eliminate prime seats (all equal, bookable!)!
2. Hats: White (occupancy counts!) · Black (phone-less excluded?!) · Green (seat-heatmaps!) — trio sampled.
3. Matrix (impact/feasibility/cost, weights $5/4/3$!): QR-check-in $24$ vs buzzers $17$ vs heatmaps $15$ — winner QR-check-in.
4. PoC question: "Do hunters *trust* displayed availability?" (riskiest unknown — stale-data risk!) — validation: $3$-day live board, accuracy-metered!
:::

::: step [Step 3: Conclusion] Final Result
Sparks-to-PoC-question in $35$′ — full cycle fluency. Riskiest-unknown extraction (PoC question from winner!) is the cycle-closing move.
:::

## 4. Active Recall Quizzes

::: quiz Q1: Mixed Drill
Matrix winner by $1$ point, weights disputed. Call?
(A) Crown it (math is math!)
(*B) Sensitivity-check first (weight-wobble flips? — robustness audit!; disputed weights ⇒ re-vote weights *then* rescore, or pilot both finalists cheaply!) — close calls trigger process, not coronations
(C) Revote till favourite wins (rigging!)
(D) Coin flip (abdication!)
::: explanation
Close-margin protocol (sensitivity + re-vote-or-dual-pilot!) respects uncertainty (scores approximate!). Coronation discipline (margins earn crowns only with robustness!) keeps sieves honest.
:::

::: quiz Q2: Mixed Drill
Storm produced $200$ sparks, $190$ junk by all accounts. Session verdict?
(A) Failure (waste!)
(*B) Success-if-banked-and-one-gem (storm economics: junk is *feedstock*, gems hide inside volume!; banking preserves option value; gem-rate tracked session-over-session for facilitation feedback!)
(C) Failure regardless
(D) Success regardless (junk unbanked = evaporated value!)
::: explanation
Volume-economics (gems-per-hundred metric!) plus banking discipline (junk logged = future feedstock/museums!). Session scored on gems+bank, not polish — storm math stated.
:::

::: quiz Q3: Mixed Drill
PoC question for QR-check-in winner above targeted *trust*, not tech. Right call because:
(A) Tech is easy always
(*B) Riskiest-unknown-first ordering (adoption risk dwarfs build risk here — working system unused = total loss!; tech risks already spiked-cheap!) — risk-ordered questions (fatal-first sequencing!)
(C) Tech questions banned
(D) Trust sounds profound
::: explanation
Fatal-first sequencing (kill-ranked unknowns!) — adoption unknowns kill *after* build spend (most expensive failure mode!). Risk-ranked question order (fatal → costly → cheap!) structures PoC portfolios.
:::
