<a id="the-intuition"></a>
## 1. The Intuition

::: callout-intuition Core Mental Model: Blueprint Sprint + Mirror Time
Sprint (promise→shape→budget→rehearse→preview→produce!), then mirror (journal: what I *did*, what it *meant*, what I'll *change* — description→meaning→commitment!). CIE's $5$ journal marks reward *shown growth* (dated entries! honest failures! linked learnings!) — portfolios evidence journeys, not perfection.
:::

## 4. Active Recall Quizzes

::: quiz Q1: Mixed Drill
DFMEA row: charger-overheat ($S9,O2,D6$). RPN + action class?
(A) $17$ (summed — RPN *multiplies*!)
(*B) $9\times2\times6=108$ → action tier (redesign: thermal cutoff + venting! + detection bump: temp telemetry *lowering D*!) — multi-lever response (design + detect!)
(C) Accept (low occurrence!)
(D) More analysis forever
::: explanation
Multiplicative RPN ($108$!) with dual-lever action (redesign *and* detectability!). Severity-$9$ floor attention regardless (high-S items reviewed even at low RPN — severity veto echo!).
:::

::: quiz Q2: Mixed Drill
Beta shows $70\%$ task success (gate: $90\%$). Call + next?
(A) Ship with training wheels (gate dodge!)
(*B) Gate-hold + diagnose (which $30\%$? clustered where?) → fix loop (targeted redesign!) → re-beta (gate re-attempt, criteria unchanged — moving goalposts banned!)
(C) Lower gate to $70\%$ (gate corruption!)
(D) Blame users (never!)
::: explanation
Gate-honouring (hold + diagnose + fix + re-attempt!) vs gate-corruption (lowering bars post-hoc!). Criteria immutability (gates set pre-evidence!) is the integrity spine — hold the line, fix the product.
:::

::: quiz Q3: Mixed Drill
Journal entry "everything went great, learned lots" grades:
(A) Full marks (positive!)
(*B) Fails rubric (undated? unlinked? failure-free = growth-free evidence! — describe→analyse→commit with concept links + honest misses required!) — mirror quality = specificity + honesty + linkage
(C) Passes on vibes
(D) Length-compensated
::: explanation
Rubric-mapped mirrors (dates! concepts! misses! commitments!) vs vacuous positivity (ungradeable!). Specificity-honesty-linkage triple is the journal quality bar — write to it deliberately.
:::
