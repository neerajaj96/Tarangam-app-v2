# Empathy + Define Workshop Drill

**Run the fortnight in an hour — mini-dossier with maps, POV, and success spec on a fresh brief.**

<a id="the-intuition"></a>
## 1. The Intuition

::: callout-intuition Core Mental Model: Pressure-Cooker Fortnight
Same stations (dig→map→diary→POV→metrics!), compressed clock (timeboxed sprints per station!), fresh brief (no canteen leftovers — hostel *water* queues this time!). Workshop discipline: timers visible, grades stamped, dissent logged.
:::

---

<a id="the-math"></a>
## 2. Theoretical Framework & Formalism

### 2.1 Workshop runbook + dossier template

Stations ($10$′ $5$-Why + $5$W sweep! → $15$′ empathy quadrants graded! → $10$′ journey curve + circled pain! → $10$′ POV + success/non-goals!) → dossier (maps + POV + metrics + dissent log!). Timer-boxing + evidence-grading throughout.

::: callout-formula KTU Formula Vault: Workshop
Timebox → grade-stamp → dissent-log → dossier.
:::

::: callout-exam KTU Exam Focus
M2 answers stage *artefacts* (maps/POVs/metrics quoted!) plus method lines (why-this-tool!). Sample-assignment echoes (reports on empathize/define phases!) reward artefact-keeping habits — keep everything, photo everything.
:::

---

<a id="worked-example"></a>
## 3. Worked Example / Step-by-Step Scenario

::: step [Step 1: Setup] Formulating the Problem
"Brief: hostel RO-water queues at $7$am. Sprint the dossier (compress!): ladder root, one quadrant set, journey pain, POV + success/non-goals."
:::

::: step [Step 2: Execution] Pressure-Cooked Dossier
1. Ladder: late-for-class ← $20$-min queues ← single RO tap per floor ← maintenance backlog ← *no ownership of uptime* (root: accountability vacuum!).
2. Quadrants (one resident, graded!): says "I skip brushing some days" (quote!) · thinks taps mock boarders (inferred!) · does carries $5$L cans upstairs (observed!) · feels resigned (inferred!).
3. Journey: wake→queue→fill→class; pain circled at *queue* (emotion floor!); backstage: warden unaware (information gap lever!).
4. POV: "Boarders need *predictable* morning water because classes punish lateness, not thirst." Success: queue-display + max-wait $5$ min in $4$ weeks; non-goal: new plumbing grid!
:::

::: step [Step 3: Conclusion] Final Result
Root-to-metrics dossier in four moves, grades and dissent attached. Fresh-brief fluency (no canteen recycling!) proves method transfer — the workshop's whole point.
:::

## 4. Active Recall Quizzes

::: quiz Q1: Mixed Drill
Timer-boxing empathy stations primarily buys:
(A) Speed records
(*B) Decision-forcing (timeboxes end deliberation with *something* — perfectionism can't stall; revisit loops scheduled, not sprawled!)
(C) Shorter reports
(D) Tired teams
::: explanation
Deliberation-bounding (decide-then-iterate beats deliberate-forever!) — timeboxes produce draft artefacts laps refine (rough-first discipline!). Bound-then-refine rhythm (not boundless polish!) paces discovery.
:::

::: quiz Q2: Mixed Drill
Dissent logs (disagreements recorded) matter because:
(A) Drama archives
(*B) Minority reads preserved (early dissent often proves right — quiet "users won't..." voices!; revisit triggers attached!) — groupthink insurance with names/dates
(C) Blame assignment
(D) Meeting minutes filler
::: explanation
Dissent-as-asset (contrarian reads banked!) with revisit hooks (re-check at test phase!) — insurance against consensus blindness. Logged-dissent culture (disagreement welcomed, recorded!) is the team health metric.
:::

::: quiz Q3: Mixed Drill
Fresh-brief (not canteen-recycled) workshop proves:
(A) Cruelty to participants
(*B) Method transfer (tools work on *new* messes — not memorised canteen answers!) — generalisation evidence (portable skill vs rehearsed script!)
(C) Better coffee breaks
(D) Canteen fatigue is real (also true, secondary!)
::: explanation
Transfer testing (novel domain, same kit!) distinguishes skill from script (rehearsed answers collapse on fresh briefs!). Novel-brief drills (routine practice!) build portable discovery muscle.
:::
