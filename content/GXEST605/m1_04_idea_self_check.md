# Idea Self-Check: Originality to Business Models

**Interrogate your brainwave — novelty, landscape, patentability, USP, manufacturability, and money-shape.**

<a id="the-intuition"></a>
## 1. The Intuition

::: callout-intuition Core Mental Model: Dragon's Den Audition (Honest Version)
**Originality** (new where? mechanism? context? bundle? — novelty *located*, not claimed!). **Landscape** (prior art + competitors mapped — white-space or red-ocean honesty!). **Patentability** (novel + non-obvious + useful — bar stated, prior-art searched!). **USP** (one-sentence why-you over them!). **Repeatability/manufacturability** (make $10{,}000$ identically? supply chains exist?!). **Business models** (who pays whom for what, repeatedly! — revenue shape, not hope!). Dragons fund audited answers, not enthusiasm.
:::

---

<a id="the-math"></a>
## 2. Theoretical Framework & Formalism

### 2.1 Self-check checklist + model menu

* Originality (locate novelty!) → landscape (map art/competitors!) → patentability screen (three bars!) → USP sentence (one breath!) → repeatability (process capability!) + manufacturability (DFM preview, M4!) → sustainability re-check (M1.3!) → business-model pick (product/service/subscription/platform/freemium—fit to buyer!).
* Kill/pivot/commit per finding (checklist *decides*, not decorates!).

::: callout-formula KTU Formula Vault: Self-Check
Novelty-located → landscape-mapped → patent-screened → USP-sentenced → makeable → money-shaped.
:::

::: callout-pitfall Patent-First Euphoria (Filing = Winning Myth!)
Filing costs (drafting + prosecution + maintenance!) without freedom-to-operate or market (paper shields, no business!) — patent *strategy* (what, where, why enforced!) precedes filing frenzy. IP economics (cost vs moat value!) gate filings.
:::

<a id="worked-example"></a>
## 3. Worked Example / Step-by-Step Scenario

::: step [Step 1: Setup] Formulating the Problem
"Coconut-husk seedling pots (biodegradable!): run the full self-check to a commit/kill/pivot verdict with numbers where cheap."
:::

::: step [Step 2: Execution] Audit to Verdict
1. Originality: material-context bundle (husk pots exist elsewhere? search! — novelty in *local waste-stream + nursery channel* if so!).
2. Landscape: plastic sleeves (incumbent, paise-cheap!) + coir majors (branded!) — white space: nurseries with green mandates!
3. Patent: process tweak likely unpatentable (obviousness risk!) — trade-secret + brand moat instead (IP honesty!).
4. USP: "Seedlings that plant pot-and-all, from waste, cheaper than coir majors." (one breath!).
5. Makeable: husk supply (seasonal gluts? storage!), mould press repeatability (tolerance trials!).
6. Money: B2B nursery subscriptions (repeat revenue!) — verdict: COMMIT to PoC with nursery letters-of-intent as gate!
:::

::: step [Step 3: Conclusion] Final Result
Located-novelty, mapped-landscape, screened-IP, sentenced-USP, makeability-trials, money-shape → gated verdict. Checklist-to-verdict (decide, with gate!) is the self-check answer spine.
:::

## 4. Active Recall Quizzes

::: quiz Q1: Foundational Concept
Freedom-to-operate (FTO) vs patentability differ by:
(A) Same search, either order
(*B) Patentability (can *I* patent? novel/non-obvious!) vs FTO (may I *sell*? others' live patents block regardless of mine!) — opposite questions (mine-ness vs clearance!), both searched pre-launch
(C) FTO is optional luxury
(D) Patents guarantee FTO (they don't — yours + theirs coexist blocking!)
::: explanation
Mine-vs-clear split (grant ≠ permission!) — FTO landscapes blocking rights (live claims covering your features!). Both-search discipline (patent screen *and* clearance map!) pre-launch, always.
:::

::: quiz Q2: Foundational Concept
USP one-sentence test fails (needs paragraphs) signals:
(A) Better storytelling needed only
(*B) Unfocused value (multi-claim muddle — customer can't repeat it, channels can't sell it!) — sharpen by subtraction (one buyer, one pain, one proof!) or pivot to a ownable edge
(C) Longer pitches work fine
(D) Nothing diagnostic
::: explanation
Repeatability-by-others test (can a fan pitch it in a breath?!) — sentence-failure diagnoses positioning fog (sharpening prescription: subtract till singable!). Positioning clarity as business asset, tested early.
:::

::: quiz Q3: Foundational Concept
Repeatability/manufacturability screening kills lab marvels when:
(A) Reviewers are jealous
(*B) Lab-tolerances ≠ line-tolerances (hand-tuned one-offs vs $10$k identical units!; supply fragility!; process windows unmapped!) — scale-down honesty (pilot-first!) precedes scale-up dreams
(C) Always, manufacturing is hard (defeatism ≠ discipline — screened, not surrendered!)
(D) Never, labs scale freely
::: explanation
Tolerance-translation audit (lab craft → line capability, Cpk-thinking!) plus supply-chain reality (fragile inputs!) gate scale claims. Pilot-as-proof (make hundreds *first*!) earns scale-up rights.
:::
