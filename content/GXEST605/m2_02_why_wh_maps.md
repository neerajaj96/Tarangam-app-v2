# 5 Why, 5W+H & Empathy Maps

**Drilling to roots and mapping minds — question ladders plus quadrant cartography with session discipline.**

<a id="the-intuition"></a>
## 1. The Intuition

::: callout-intuition Core Mental Model: Root Archaeology + Mind Cartography
**5 Why** digs strata (symptom → … → root cause/systemic layer — stop at actionable depth, not philosophy!). **5W+H** (Who/What/When/Where/Why/How!) surveys the site completely (no blind faces!). **Empathy maps** chart one user (Says/Thinks/Does/Feels quadrants — observed vs inferred labelled!). **Session discipline**: before (recruit diverse, prime open-ended, silence phones!), during (one-speaks-at-a-time, defer judgment, quantity!), after (cluster affinities, vote dots, insight sentences!).
:::

::: anim empathy-map Four Rooms, One Mind
Says and does (observed!) on the diagonals from thinks and feels (inferred!) — label every sticky note's evidence grade.
:::

---

<a id="the-math"></a>
## 2. Theoretical Framework & Formalism

### 2.1 Ladders + quadrants + session protocol

* 5 Why (causal descent, $5\pm2$ depth, actionable stop!) + 5W+H (coverage completeness per finding!).
* Quadrants (says: quotes! thinks: beliefs! does: actions! feels: emotions! — evidence-graded: observed vs inferred!).
* Protocol (before/during/after checklists!) + affinity clustering (theme emergence!) + insight sentences (user-needs-because format!).

::: callout-formula KTU Formula Vault: Dig + Map
Why-ladder to **actionable root** · W+H for **coverage** · quadrants **evidence-graded** · sessions **protocolled**.
:::

::: callout-pitfall Inferred-Quadrant Laundering (Guesses as Quotes!)
Thinks/feels filled with facilitator fiction presented as user voice (fabricated empathy!) — evidence-grade labels (observed/inferred!) + verification loops (member-checking!) keep maps honest. Grade-stamp every note.
:::

<a id="worked-example"></a>
## 3. Worked Example / Step-by-Step Scenario

::: step [Step 1: Setup] Formulating the Problem
"Canteen queues overflow: (a) 5-Why chain (3+ levels shown!)? (b) 5W+H sweep gaps? (c) Mini empathy map (one student, graded notes!)? (d) Session plan (before/during/after lines!)?"
:::

::: step [Step 2: Execution] Dig, Sweep, Map, Plan
1. (a) Long queues → counters understaffed peak → shifts fixed historically → scheduling never data-driven → *root: no demand-sensing rostering* (actionable system fix, not "hire more" reflex!).
2. (b) Who (day-scholars peak!) · What (thali only!) · When ($12$:$30$–$1$!) · Where (counter $2$ bottleneck!) · Why (class timetable clump!) · How (token chaos!) — gaps flagged per W (missing night-shift data? ask!).
3. (c) Says "always late to class" (quote-observed!) · Thinks "canteen disrespects my time" (inferred — grade it!) · Does skips lunch twice weekly (observed!) · Feels resigned and rushed (inferred, member-check!).
4. (d) Before: diverse eaters + consent + timers · During: timeboxed sharing, no-fixing rule · After: affinity-cluster + insight votes + photo-log.
:::

::: step [Step 3: Conclusion] Final Result
Laddered root, swept Ws, graded quadrants, protocolled session. Grade-stamps + actionability-stops (ladder depth, inference labels!) are the rigour marks.
:::

<a id="self-check"></a>
## 4. Active Recall Quizzes

::: quiz Q1: Foundational Concept
5-Why stopping rule (actionable depth) prevents:
(A) Deep thinking (depth wanted — to *actionable*!)
(*B) Philosophical infinite regress (why-gravity spirals!) vs symptom-shallowness (first-answer settling!) — stop where levers appear (system-actionable causes!)
(C) Team disagreement
(D) Documentation
::: explanation
Lever-test per level (can we act here?) — actionable = stop and design; philosophical = overshot (climb back!). Depth discipline (lever-gated!) keeps ladders productive, not performative.
:::

::: quiz Q2: Foundational Concept
Affinity clustering after empathy sessions does:
(A) Decorates walls colourfully
(*B) Emergent theming (notes self-organise into insight clusters — patterns beat piles!; dot-voting prioritises!) — synthesis (not summary!) producing insight sentences per cluster
(C) Counts sticky notes
(D) Assigns blame
::: explanation
Emergence over enumeration (themes surprise!) — clustering *analyses* (relations appear!), listing merely stores. Insight-per-cluster output (user-needs-because sentences!) is the deliverable, not the wall photo.
:::

::: quiz Q3: Foundational Concept
Member-checking (verifying maps with users) guards against:
(A) Slow sessions
(*B) Facilitator fiction (inferred quadrants drifting from user truth!) — validation loop (users correct maps!) keeps empathy *theirs*, not ours (laundered-guess prevention!)
(C) Too many notes
(D) Diverse recruits
::: explanation
Inference-audit loop (show maps back! — "did we get you right?") — humility mechanism (maps are hypotheses till confirmed!). Confirmed-maps-only forward (unverified stays flagged!) is the honesty protocol.
:::
