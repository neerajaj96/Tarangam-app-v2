<a id="worked-example"></a>
## 3. Worked Example / Step-by-Step Scenario

::: step [Step 1: Setup] Formulating the Problem
"E-bike retrofit kits for delivery riders: (a) lifecycle + first gate? (b) Three-lens wobble hunt? (c) TRL today (garage prototype!) + evidence-to-next? (d) Self-check one-line USP + verdict?"
:::

::: step [Step 2: Execution] Sprint Answers
1. (a) Concept/needs boundary — gate: $20$-rider pain interviews + willingness math (evidence or kill!).
2. (b) Desirable? (rider fuel math!) · feasible? (certified-safe batteries?!) · viable? (financing for riders?!) — battery-safety wobble flagged first (liability!).
3. (c) TRL $3$–$4$ (garage proofs!) → $5/6$ needs road-pilot with metered range/safety logs (relevant environment!).
4. (d) USP: "Petrol savings that pay the kit before it wears out." Verdict: COMMIT to pilot-gated PoC (safety certification as hard gate!).
:::

::: step [Step 3: Conclusion] Final Result
Gate-evidence, lens-wobbles, rung-evidence, USP-verdict — sprint completeness in four breaths. Safety-flagged wobbles (liability lenses!) get priority naming always.
:::

## 4. Active Recall Quizzes

::: quiz Q1: Mixed Drill
Idea with proven demand + working tech, no payer identified. Lens verdict + next lap?
(A) Ship it (two legs suffice? No — stool rule!)
(*B) Viability wobble (desirable∩feasible, payer-missing!) — next lap: business-model experiments (who-pays pilots: riders? fleets? advertisers?!) before scale spend
(C) Kill instantly (wobbles pivot, not necessarily kill — lap it!)
(D) Rebuild tech (wrong leg!)
::: explanation
Leg-specific diagnosis (name the wobbling leg precisely!) routes laps (viability gaps → money experiments, not tech rebuilds!). Wobble→lap mapping (each gap owns a next experiment!) is the lens discipline.
:::

::: quiz Q2: Mixed Drill
TRL-$6$ claim with lab-only evidence. Audit?
(A) Accept (team confident!)
(*B) Downgrade to $4$ (relevant-environment proof missing!) + prescribe harbour/road pilot with metered curves (evidence-to-rung!) — claims graded by proof-type match
(C) Upgrade to $7$ (optimism!)
(D) Ignore TRL framing
::: explanation
Proof-type matching (lab≠relevant-environment!) audits rung claims (evidence must fit the rung!). Downgrade-plus-prescription (honest rung + path up!) beats binary accept/reject.
:::

::: quiz Q3: Mixed Drill
Community project designed without one local meeting. Verdict?
(A) Efficient process (speed!)
(*B) Parachute flag (zero engagement receipts — co-design absent!) — remedy: immersion sprint + decision-rights sharing before further spend (gates halted till receipts exist!)
(C) Fine if engineers are senior
(D) Document it nicely (theatre+paperwork!)
::: explanation
Receipt-gated spending (no engagement proof = no next budget!) enforces anti-parachute discipline structurally. Halt-till-receipts (process circuit-breaker!) is the governance teeth.
:::
