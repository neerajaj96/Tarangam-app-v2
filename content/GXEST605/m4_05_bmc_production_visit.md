# BMC, Production Plan & Industrial Visit

**One-page business, full-scale making, and learning from factory floors — the syllabus assignments, worked.**

<a id="the-intuition"></a>
## 1. The Intuition

::: callout-intuition Core Mental Model: Postcard Business + Factory Field Trip
**Business Model Canvas** (one-page business: partners/activities/resources/value/relationships/channels/segments/costs/revenues — nine boxes, mutual consistency *audited*!). **Production plan** (full-scale making: volumes, lines, staffing, QC gates, logistics, spares!). **Industrial visit** (factory-floor university: standards/procedures observed live, report distils learnings!). Postcard clarity (BMC!), making completeness (plan!), floor wisdom (visit!) — commercial readiness trio.
:::

## 2. Theoretical Framework & Formalism

### 2.1 BMC nine + production anatomy + visit method

* BMC boxes + fit checks (value↔segment! activities↔resources! costs↔revenues! — internal consistency audited!).
* Production plan (demand→capacity→line balancing→staffing→QC→pack/ship→spares/service!).
* Visit method (observe with framework: standards/procedures/safety/quality-culture!; report: learnings→implications-for-our-product!).

::: callout-formula KTU Formula Vault: Commercial Trio
BMC **nine-box fit** · plan **demand-to-spares** · visit **observe-to-implicate**.
:::

<a id="worked-example"></a>
## 3. Worked Example / Step-by-Step Scenario

::: step [Step 1: Setup] Formulating the Problem
"QR-token venture: (a) BMC nine boxes (one line each!)? (b) Production plan headings for $500$ units? (c) Visit-report learnings→implications (display factory!)?"
:::

::: step [Step 2: Execution] Postcard, Plan, Floor
1. (a) Partners (tablet vendor, canteen coop!) · Activities (assembly, install, support!) · Resources (jigs, spares, field team!) · Value (queues→certainty!) · Relationships (warden champions!) · Channels (campus pilots→tenders!) · Segments (canteens, messes!) · Costs (hardware+support!) · Revenues (unit+AMC!) — fit-checked (support cost ↔ AMC revenue!).
2. (b) Demand ($500$ firm!) → line stations → staffing → QC gates (scan-rate sampling!) → pack/ship → spares ($10\%$!) → service rota.
3. (c) Learnings (ESD discipline! traveller audits! Andon cords!) → implications (our assembly jig + test script + stop rule!).
:::

::: step [Step 3: Conclusion] Final Result
Fit-checked BMC, demand-to-spares plan, learning-to-implication visit notes. Fit-checking (box-vs-box consistency!) is the BMC quality bar — audit pairs, don't just fill.
:::

<a id="self-check"></a>
## 4. Active Recall Quizzes

::: quiz Q1: Foundational Concept
BMC fit-checking (box consistency) catches:
(A) Spelling errors
(*B) Model incoherence (premium value + budget channels! high-touch relationships + freemium revenues! — box-vs-box contradictions!) — internal-consistency audit before external pitch.
(C) Market sizes
(D) Team gaps only
::: explanation
Coherence-as-quality (boxes must agree!) — contradiction hunts (value↔segment, cost↔revenue, activity↔resource!) stress-test logic on paper. Incoherence found cheap (canvas!) beats found broke (market!).
:::

::: quiz Q2: Foundational Concept
Spares provisioning ($10\%$ rule-of-thumb) economics:
(A) Inventory hobbyism
(*B) Downtime-cost vs carrying-cost balance (stockout stalls vs shelf-space cash!; criticality-weighted: custom boards deeper than screws!) — service-level math, not superstition.
(C) Vendor kickbacks
(D) Round numbers comfort
::: explanation
Stockout-cost vs holding-cost frontier per part criticality (ABC-stratified spares!) — differentiated provisioning (critical-deep, trivial-lean!). Math-tuned spares (modelled, not memorised!) is the ops answer.
:::

::: quiz Q3: Foundational Concept
Visit reports implicate (not just describe) by:
(A) Longer descriptions
(*B) Learning→implication pairs (observed practice → *our* action: traveller-audits ⇒ *our* assembly checklist!) — implication discipline per observation (so-what-for-us!)
(C) Photo counts
(D) Signature sheets
::: explanation
So-what pairing (every learning lands an implication!) converts tourism to transfer (field wisdom becomes design changes!). Implication-per-observation format (two columns!) structures reports that change things.
:::
