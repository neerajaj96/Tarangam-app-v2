## 4. Active Recall Quizzes

::: quiz Q1: Mixed Drill
AEs vs GANs generative philosophies differ by:
(A) Nothing, both sample
(*B) Likelihood/reconstruction (cover data, blurry-averaged!) vs adversarial (sharp samples, mode-dropping!) — coverage-vs-fidelity frontier (hybrid VAE-GANs negotiate middle!) — frontier framing, not winner-picking
(C) GANs always win
(D) AEs always win
::: explanation
Blurriness (mean-seeking!) vs sharpness-with-gaps (mode-seeking!) — objective-shapes dictate failure *styles*. Frontier literacy (which failure affordable per use!) picks philosophies — use-case sovereignty, always.
:::

::: quiz Q2: Mixed Drill
Synthetic GAN data for training classifiers: verdict protocol?
(A) Always helps (more data!)
(*B) Fidelity-gated (does synthetic match real *slices*? FID-per-class!), utility-tested (ablate: +synthetic vs +real-collection-cost!), shift-monitored (synthetic bias audits!) — gated adoption, never blind augmentation
(C) Never helps
(D) Untestable claim
::: explanation
Synthetic value = measured downstream deltas (with shift audits!), not vibes. Gate protocol (fidelity→utility→monitor!) decides adoption per case — evidence-gated enthusiasm.
:::

::: quiz Q3: Mixed Drill
Deployment-gate order (slices, calibration, drift, latency):
(A) Any order, checklist only
(*B) Correctness-slices first (who fails!), calibration second (trust scores!), drift third (staying right!), latency last (fast *enough* — correctness gates speed, never reverse!) — gate *sequence* encodes values (safety before speed!)
(C) Latency first always
(D) Skip drift initially
::: explanation
Sequence is moral (right→trusted→staying-right→fast-enough!) — latency-first ships fast wrongness. Ordered gates (with owners/dates!) are the launchpad liturgy — recite in order.
:::
